# 00 - 项目概述

> 本文档为「静坐觉察」（Meditation Awareness）微信小程序的逆向工程文档第一篇，从源码逆向提取而成，与仓库根目录的英文 `CODEBUDDY.md` 互为补充。所有逆向文档统一存放于 `工程文档/` 目录下。

## 1. 项目定位

「静坐觉察」是一款基于**微信云开发（CloudBase）**的冥想打卡类小程序，提供：

- 冥想计时（正念静坐）
- 每日打卡 / 打卡记录
- 体验笔记（心得记录）
- 实时排行榜、勋章成就
- 团队（空间）功能与邀请流程

产品名（导航栏标题）：**静坐觉察**。用户默认昵称：未登录为 `觉察者`，新建档案为 `静心者`。

## 3. 目录边界

```
meditation/
├── miniprogram/              # 小程序前端源码（miniprogramRoot）
│   ├── app.js / app.json     # 云初始化、缓存状态、页面与分包、tabBar
│   ├── pages/                # 主包页面（12 个）
│   ├── subpackages/team/     # 团队分包（4 个页面）
│   ├── utils/                # 前端业务模块
│   ├── workers/              # 计时 worker
│   ├── config/images.js      # 云存储 fileID 配置
│   └── audio/风铃声.mp3       # 提示音
├── cloudfunctions/           # 云函数（cloudfunctionRoot）
│   ├── meditationManager/    # 主后端（登录/记录/统计/排行/勋章/档案）
│   ├── teamManager/          # 团队 CRUD、邀请、加入、成员打卡
│   ├── autoCreateCollections/# 一次性建集合 + 样例数据
│   ├── cleanupTestData/      # 测试数据清理（stats/safe/full）
│   └── getRandomWisdom/      # 随机智慧语
├── scripts/                  # Node 辅助脚本（清理工具等）
├── create_collections_consistent.js   # 数据 schema 参考（镜像 API 字段）
├── file_index.json           # 背景图文件清单
└── project.config.json / project.private.config.json
```

**边界原则：**
- 前端**仅**通过 `wx.cloud.callFunction` 调用云函数，且统一收敛在 `miniprogram/utils/cloudApi.js`。
- 云函数之间不互相调用，各自独立部署。
- 云环境 ID 在云函数内部通过 `cloud.DYNAMIC_CURRENT_ENV` 读取，前端硬编码在 `config/images.js` 的 `CLOUD_PREFIX`。
