# 01 - 架构设计

> 逆向自 `miniprogram/app.js`、`miniprogram/utils/checkin.js`、`miniprogram/utils/cloudApi.js`、`cloudfunctions/meditationManager/index.js`、`cloudfunctions/teamManager/index.js`。

---

## 1. 两层架构总览

```
┌─────────────────────────────┐         wx.cloud.callFunction         ┌────────────────────────────┐
│      小程序前端 (miniprogram) │ ───────────────────────────────────▶ │      云函数 (cloudfunctions) │
│  pages / subpackages / utils │                                       │  meditationManager          │
│  workers / components        │ ◀─────────────────────────────────── │  teamManager                │
└─────────────────────────────┘     {success, data, error} 信封        │  getRandomWisdom 等          │
                                        (统一封装于 cloudApi.js)          └────────────┬───────────────┘
                                                                                      │ 云数据库 / 云存储
                                                                                      ▼
                                                                              wx-server-sdk (db / storage)
```

**约束（逆向得到的硬规则）：**
- 前端**不允许**直接访问数据库或写云函数逻辑，所有后端调用经 `wx.cloud.callFunction`，且**统一收敛在 `miniprogram/utils/cloudApi.js`**（新增接口应在此加方法，而非在页面里直接调 `wx.cloud.callFunction`）。
- 云函数统一返回 `{ success: boolean, data?, error? }` 信封（个别快照接口还带 `message`）。
- 云函数读取环境用 `cloud.DYNAMIC_CURRENT_ENV`，因此同一份代码可跨环境运行，无需硬编码。

## 2. 单一调度（dispatch）模式

云函数入口是 `exports.main`，内部用 `switch (event.type)` 分发到具名处理函数。新增后端能力 = 在 `switch` 里加一个 `case` + 一个 `async` 函数。

**`meditationManager/index.js`**（约 20 个 `event.type`）：
```js
exports.main = async (event, context) => {
  if (event.Type === 'timer') return await generateRankingSnapshot({ type: 'daily' });
  const openid = cloud.getWXContext().OPENID;
  switch (event.type) {
    case "login": ...
    case "recordMeditation": ...
    // ... 见 03-云函数接口契约
  }
};
```

**`teamManager/index.js`** 采用同样模式，按 `event.action` 分发（注意团队云函数用的是 `event.action` 而非 `event.type`，逆向时易混淆）：
```js
switch (event.action) {
  case "createTeam": ...
  case "joinTeam": ...
  case "generateInvite": ...
  // ...
}
```

> 📌 两个云函数的分发字段名不同：`meditationManager` 用 `event.type`，`teamManager` 用 `event.action`。前端 `cloudApi.js` 已分别封装，调用时须用对字段名。

## 3. 本地优先身份模型（Local-first Identity）

这是本项目最关键的架构决策，逆向自 `miniprogram/utils/checkin.js` 与 `pages/index/index.js`：

1. **首次启动**：生成一个 `local_<timestamp>_<random>` 形式的本地 ID，写入存储键 `localUserId` 与 `userOpenId`。
2. **微信登录后**：真实 `openid`（形如 `oz...`）替换 `userOpenId` 的值。
3. **映射持久化**：`openid` 与旧 `local_user_id` 的对应关系写入 `user_mappings` 集合（由 `meditationManager.createUserMapping` / `migrateLocalData` 处理）。
4. **缓存键**：所有按用户维度的本地缓存都挂在 `meditation_checkin_<userId>`（`userId` 为本地 ID），因此登录迁移后数据仍可续接。

**前端取身份的约定（逆向规则）：**
- 需要本地 ID 时调用 `checkinManager.getUserId()`（返回本地 id）。
- 需要 openid 时读 `wx.getStorageSync('userOpenId')`（登录后才有）。
- **不得假设用户已登录**——大量页面在匿名状态下也要能运行。

默认昵称：未登录 `觉察者`，新建档案 `静心者`。

## 4. 缓存恢复流程（Cache Recovery）

逆向自 `miniprogram/app.js` 的 `onLaunch` 与 `miniprogram/utils/checkin.js`：

```
app.onLaunch
   └─ setupCacheStatus()
        ├─ 首次启动 或 版本变更 → cacheStatus = 'initialized', needsRecovery = true
        └─ 否则保持原值
   └─ checkinManager.strictCacheCheck()
        ├─ 读取 cacheStatus / needsRecovery
        ├─ checkCriticalDataExists()   关键数据是否存在
        ├─ hasActualUserData()         是否已有真实用户数据
        └─ 命中恢复条件 → 从云端重建本地状态
```

- `appVersion` 目前**硬编码为 `1.0.0`**。需要"升级时迁移数据"时，应提升此版本号触发恢复逻辑。
- 触发时机：首次启动、版本号变化。

## 5. 实时排行榜 vs 遗留排行榜

- **实时计算**：`getRankings` 直接查询 `user_stats`，按 `dailyTotalDuration` 降序，取前 100 名（`limit(100)`）；当前用户不在前 100 时再查一次全量定位其真实排名。
- **遗留集合**：`rankings` 集合仍由 `updateRankings`（每次打卡调用 `recordMeditation` 时触发）写入日/月/总三张榜，但 `getRankings` **已不读取**它。
- **快照**：`generateRankingSnapshot` 由定时器每 6 小时触发一次，将前 1000 名写入 `ranking_snapshots` 集合。

> 这是典型的"写时双写、读时换新"过渡态，详见 `07-已知问题与技术债.md`。

## 6. 计时与音频

- `pages/timer/timer.js` 用 `wx.createBackgroundTimer` 做前台计时，并用 `miniprogram/workers/timer-worker.js` 做精确秒级更新。
- `wx.onAppShow` 时调用 `syncTimerTime()`，用墙钟时间戳（`startTimestamp` / `pauseTimestamp` / `totalPausedTime`）纠正前后台切换产生的漂移。
- 控制屏幕亮度（`saveCurrentBrightness` / `setKeepScreenOn`），播放云存储中的引导音频 `defaultMusicFileID`。
- 提示音：`audio/风铃声.mp3`。
