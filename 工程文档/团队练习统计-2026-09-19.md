# 团队练习统计与验收

日期：2026-09-19。本次扩展替代 2026-09-18 审查报告中的创建数量限制与旧版统计交互。

## 功能与统计口径

- 团队列表、详情、创建和邀请加入页沿用小程序现有样式：浅灰背景、白色卡片、深灰文字、品牌金色操作；详情页签对齐练习记录页，设置表单对齐首页打卡表单。
- 同一账号可创建多个团队，每个团队独立保存统计起始日期和每日目标。团队名称仍不能重复。
- 创建时默认从当前练习日开始、每天 20 分钟；目标支持 1–1440 的整数分钟，日期不能晚于当前练习日。
- 练习日固定为北京时间当日 02:00（含）至次日 02:00（不含）。当日多次练习时长累加。
- **今日练习**默认显示待关注成员：先列尚未练习，再列时长不足；可切换已达标、全部，也可点人数卡片分别筛选。
- **历史统计**从团队起始日期至昨日，显示每位成员的练习天数、未达标天数、已达标天数，并拆分未练习与时长不足。当天尚未结算，不计入历史。
- 练习天数指累计有效时长大于零的天数。未达标天数包含未练习日；`未达标 = 未练习 + 有练习但不足目标`。
- 全体当前成员使用同一起始日期，不按加入日期截断。修改规则后，历史按新规则重新计算。
- 创建者可在详情右上角“设置”修改规则、解散团队；其他成员通过“规则”查看。解散需要确认，不删除个人练习记录，也不影响其他团队。
- 页面在再次显示、下拉刷新和跨过凌晨 02:00 时重新获取统计；其他成员新提交的记录通过刷新查看。

## 手工验收

在测试云环境更新 `teamManager` 云函数并编译当前小程序。准备 A（创建者）、B、C 三个微信测试账号，使用开发者工具和手机交叉验证。请使用测试团队和测试练习记录。

| 操作 | 预期 |
| --- | --- |
| A 连续创建“晨练组”和“晚练组”，分别设 20、30 分钟及不同起始日期 | 两个团队都出现在我的团队列表；重新进入小程序后，各自规则不变 |
| A 邀请 B、C 加入晨练组 | 同一有效邀请可供不同成员加入；重复加入不增加人数 |
| 当前练习日 A 累计 20 分钟、B 累计 12 分钟、C 不练习 | 当天汇总分别为 1 人达标、1 人时长不足、1 人尚未练习；默认先 C 后 B；B 显示还差 8 分钟 |
| B 再练习 8 分钟，A 刷新详情 | B 累计 20 分钟并移到已达标，待关注人数减少 |
| B 查看详情规则 | 可查看起始日期与目标，但无保存或解散操作 |
| A 保存新的起始日期与目标，退出详情后重进；B 刷新 | 两个账号看到相同新规则和重新计算的统计，晚练组不变 |
| 保存时断网或令云请求失败 | 不提示保存成功，保留编辑内容并允许重试 |
| A 在设置中取消解散，再确认解散晨练组 | 取消时无变化；确认成功后该组从列表消失，晚练组与个人练习记录仍在；旧邀请无法加入 |
| 小屏手机打开设置并调出数字键盘 | 目标输入框可见，内容可滚动；收起键盘后保存、解散按钮可访问 |

### 历史计算示例

设当前练习日为 D，统计开始日期为 D−5、目标 20 分钟。为 B 准备以下测试记录：

| 练习日 | 有效练习 |
| --- | --- |
| D−5 | 10 分钟 |
| D−4 | 12 分钟 + 8 分钟 |
| D−3 | 无 |
| D−2 | 25 分钟 |
| D−1 | 无 |

预期历史统计：共 5 天，练习 3 天，达标 2 天，未达标 3 天，其中未练习 2 天、时长不足 1 天。D 当天的记录不改变这组历史数值。改为每日 30 分钟后，练习仍为 3 天，达标 0 天，未达标 5 天。

### 凌晨边界

测试环境中，某日北京时间 01:59:59 的记录属于前一个练习日，02:00:00 的记录属于当天。优先按精确时间戳划分；历史记录缺少有效精确时间戳时，兼容使用有效的 `date` 字段，无法还原此类旧记录的小时信息。

## 实现与发布说明

- 团队文档保存 `practiceStartDate` 和 `dailyGoalMinutes`，旧团队读取时默认使用创建时所在练习日与 20 分钟，不要求预先迁移。
- `getTeamPracticeReport` 仅允许团队成员调用，云端汇总后返回成员统计，不向客户端下发原始练习记录。
- 练习记录按 `_id` 游标分页，避免并发新增或删除改变分页位置而重复累计、漏算记录。
- 为兼容旧记录的多种时间格式，按当前成员分批读取练习记录并在云端过滤统计区间。长历史、大量记录场景仍需观察耗时，后续可通过规范化练习日字段与索引优化。
- 生效需要部署 `cloudfunctions/teamManager` 并更新包含团队页面、工具模块的小程序。本次仅修改本地代码。

## 本次补充：团队成员与完整编辑

本节更新前文的创建默认值与详情入口说明。详情改为「团队成员」「查看记录」两个主页签；查看记录包含「今日练习」「历史统计」。成员页显示完整昵称与独立团长标签、累计次数/分钟、最近练习时间；顶部显示人数、累计练习次数与今日活跃度。团长通过「编辑团队」修改名称、介绍、头像及练习设置，其他成员仅查看规则。

新建时起始日期、期望分钟均可不填，云端保存为 `null`；编辑也可清空。起始日期未设置时从团队创建所属练习日统计，期望分钟未设置时仅区分已练习/尚未练习，历史显示实际天数、分钟和未练习天数，不显示达标判断。历史团队缺少字段时仍沿用创建日和 20 分钟，已有有效设置不变。

报告 `settings` 增加 `effectivePracticeStartDate`（实际统计起点）和 `hasPracticeStartDate`。成员增加 `totalPracticeCount`、`cumulativeMinutes`、`todayPracticeCount`、`lastPracticeAt`、`lastPracticeDate`；累计值从实际起点至今日，历史 `totalMinutes` 仍不含今日，仅计当前成员的有效正时长记录。`overview` 返回人数、累计次数、今日练习人数及整数百分比活跃度；无精确时间的旧记录只显示日期，不补造练习时间。验收另覆盖空设置创建/清空、完整资料编辑、无目标统计、长昵称、返回页面刷新与保存取消后的加载恢复；接口字段详见《03-云函数接口契约》。

## 成员卡片查看练习明细

历史统计卡片可点击进入结束日所在月份的成员记录，成员名单卡片进入当前月，今日卡片进入当日。复用 `checkinHistory` 与 `history` 页面，切换月份、日期和按日/按月视图时保留所选成员；页首显示成员昵称、头像与统计起点。记录从团队有效统计起点开始，仍按北京时间 02:00 分日。

新增 `getTeamMemberPracticeRecords` 接口校验查看者与目标成员的当前团队身份，仅返回练习时间和时长，不读取个人感受、日记缓存。成员模式隐藏删除入口并在事件处理层禁止删除。页面包含加载、空记录与失败重试状态，账号切换或页面退出后的过期响应不会覆盖当前数据。

## 历史团队汇总卡片

「查看记录 → 历史统计」沿用今日练习的三栏卡片样式，在成员列表前展示未达标人数、累计未达标人次和总体达标率。卡片下方拆分未练习、时长不足各自的人数与人次，并显示当前成员总数、全程达标人数。

- 人数为统计期间曾出现对应状态的当前成员数，按成员去重；同一成员可能同时计入未练习和时长不足两类人数。
- 每人每天计 1 人次，累计未达标人次为成员 `unmetDays` 之和，等于未练习人次加时长不足人次，不按单次练习条数计算。
- 总体达标率为达标人次 ÷（当前成员数 × 历史天数），最多保留一位小数；尚有未达标日时不会四舍五入显示为 100%。全程达标仅包含期间每天均达标的成员。
- 未设置期望分钟时，改为未练习人数、累计未练习人次、练习参与率及每天都练习人数，不作达标判断。
- 仍按统一起始日至昨日统计，今日不计入；首日保留原有空状态，加载失败不展示旧汇总。汇总直接使用现有报告，无需新增接口或部署云函数。

## 点击历史统计查看成员与日期

历史汇总的未达标人数、人次打开未达标明细，达标率打开全部每日练习明细；未练习、时长不足拆分行打开对应筛选。成员卡片的未达标天数及底部未练习、时长不足天数可直接查看该成员的对应日期，卡片其他区域仍打开原有月度记录。

新增 `historyDetails` 页面按日期倒序展示成员、状态和当日累计分钟；时长不足时补充与目标相差的分钟数。支持切换筛选、分页加载、下拉刷新、失败重试；无目标时只区分未练习与全部，不展示达标判断。点击具体成员日期可进入该成员的原有日记录页。

新增云接口 `getTeamHistoryDetails` 与历史报告共用统计口径，不下发感受或日记。每页最多返回 100 条成员日明细，缺少练习记录的日期仍可列出为未练习。权限、分页、02:00 边界、今日排除、无目标、筛选与加载竞态通过自动化测试验证；上线此明细功能需要更新 `teamManager` 云函数和小程序。

## 历史总览与按月明细

历史统计主页面展示从团队有效起始日期至昨日的全部历史，移除月份选择器，卡片显示累计未达标、总体达标率及全程达标人数，成员历史天数和分钟也按完整区间统计。只有点击统计进入明细后才按月查看，默认当前练习日所属月份，可点上月、下月、月份选择器或「回到本月」切换；切换月份保留成员与状态筛选。

明细所选月的统计区间取团队有效起始日期至昨日与该自然月的交集；本月不计今日，过去月份最多包含完整自然月，最早月份不包含团队统计起点之前的日期。月初尚无已结束练习日时显示空状态，仍可切换上月。月份边界按北京时间 02:00 的当前练习日确定；未来月或早于起点的月份不可通过控件选择。

两个接口支持可选 `month` 参数：历史统计主页面请求报告时不传月份，明细页面始终传入所选月份。今日练习、团队成员累计次数/分钟和最近练习维持原有口径。明细月内分页不会追加其他月份，切换月份即清空旧数据并忽略迟到响应，加载失败可重试。已部署按月接口时，本次恢复总览只需重新编译小程序。
