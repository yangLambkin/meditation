# 「我」页面统计

当前入口为 `miniprogram/pages/me/me.js` 的 `calculateUserStatistics` / `getUserStatisticsFromCloud`。登录判断复用 `checkinManager.isUserLoggedIn()`，实例锁 `_loadingStats` 避免生命周期重复请求；未登录时四项显示为 0。

| 展示字段 | 正常读取 | 云端失败时 |
| --- | --- | --- |
| `totalMinutes` | `user_stats.monthlyStats[业务月].totalDuration` | 本机 `getCurrentMonthMinutes()` |
| `longestCheckInDays` | `user_stats.longestCheckInDays` | 0 |
| `currentStreak` | `user_stats.currentStreak` | 0 |
| `medals` | 云端勋章合并与本次评估后的本机已解锁数 | 本机已解锁数 |

业务月使用 `dateUtil.getBusinessMonth()`，按北京时间 02:00 换日。在线统计以云端已确认记录为准，离线回退不代表云端已完成补传或重算。

勋章评估使用历史最长连续天数、累计天数、累计分钟和 `maxSingleDuration`（兼容回退到最近时长），连续勋章不会因当前连续天数中断而丢失。配置、阈值、终身成就和登录迁移规则见 [用户等级与勋章](10-用户等级与勋章逻辑.md)。

本机月度统计带有效期缓存；数据写入与恢复修改后需核对缓存失效。维护时分别验证云端成功、失败、未登录、换月和离线补传后的展示，不能把回退的本机时长当成完整云端统计。
