# 05 - 前端模块地图

> 逆向自 `miniprogram/app.json`、`pages/`、`subpackages/team/`、`components/`、`utils/`。所有前端后端调用经 `cloudApi.js`。

---

## 1. 应用骨架

| 文件 | 职责 |
| --- | --- |
| `app.js` | 云初始化、缓存状态 (`setupCacheStatus`)、音频选项、版本检查；`appVersion` 硬编码 `1.0.0` |
| `app.json` | 主包 `pages`（12 个）、分包 `subpackages`（team）、tabBar（4 个：首页/计时/团队/我） |
| `app.wxss` | 全局样式 |

### tabBar（4 个）
首页 / 计时 / 团队 / 我 —— 对应 `pages/index`、`pages/timer`、`pages/team`、`pages/me`。

---

## 2. 主包页面（`pages/`）

| 页面 | 职责 |
| --- | --- |
| `index` | 首页，打卡入口、身份初始化（本地 ID + 登录迁移） |
| `example` | 示例/调试页 |
| `timer` | 冥想计时（App 倒计时会话 + 时间戳刷新 + 屏幕常亮 + 起收坐提示音与可选引导） |
| `recorder` | 打卡记录录入 |
| `daily` | 每日打卡视图 |
| `me` | 我的（个人中心） |
| `history` | 历史记录 |
| `profile` | 用户档案（登录/补全；承接邀请流 `fromPage`/`fromParams` 回跳） |
| `badge` | 勋章墙 |
| `team` | 团队列表（主包团队入口） |
| `test` | 测试页 |
| `test/inviteTest` | 邀请流测试 |

---

## 3. 团队分包（`subpackages/team/pages/`）

> 分包声明：root `subpackages/team`，name `team`；含 4 个页面。

| 页面 | 职责 |
| --- | --- |
| `createTeam` | 创建团队（名称/图标） |
| `teamDetails` | 团队详情（成员、打卡数据 `getTeamMembersCheckinData`/`getMemberWeekCheckin`） |
| `joinTeam` | 通过邀请参数加入（`teamId`/`inviteId` 等） |
| `testJoinTeam` | 加入流程测试 |

邀请参数经 query 传递：`teamId` / `teamName` / `teamIcon` / `inviterName` / `inviteId`。

---

## 4. 共享组件（`components/`）

当前项目无独立共享组件目录。

---

## 5. 业务工具库（`utils/`）

| 文件 | 职责 | 备注 |
| --- | --- | --- |
| `cloudApi.js` | **统一封装所有 `meditationManager` 调用** | 新增后端能力在此加方法 |
| `checkin.js` | 本地优先身份、缓存键、`getUserId`、`strictCacheCheck`、`migrateLocalData` 流程 | 运行版 |
| `badgeManager.js` | 勋章配置与本地解锁评估，配合 `updateUserBadges` | 图片用云存储 URL |
| `images.js` | 每日扑克图集 fileID 配置（`CLOUD_PREFIX`） | |
| `teamManager.js` | 团队相关前端封装（调用 `teamManager` 云函数） | |
| `lunar.js` | 农历依赖（npm 包 `lunar` 构建产物） | |

---

## 6. 计时会话

| 文件 | 职责 |
| --- | --- |
| `utils/countdownSession.js` | App 持有倒计时会话，以时间戳计算时长、保存检查点与完成草稿；前台每秒刷新，并在刷新循环丢失时有限恢复 |
| `utils/timerAudio.js` | 音频准备、暂停、中断与页面重建后的恢复，独立于计时和记录 |
| `utils/cuePlayer.js` | 原生铃声播放器管理、旧回调隔离、报错/启动卡住后有限重建 |
| `utils/timerInterruption.js` | 区分明确退出与系统临时遮挡，供 App 和页面使用 |
| `utils/screenBrightness.js` | 在计时页调暗并恢复实际捕获的屏幕亮度 |

计时不使用 Worker；旧的未启用 `timer-worker.js` 已移除。正计时暂由 `pages/timer/timer.js` 管理。

## 8. 依赖与构建

- `miniprogram/package.json` 依赖 `lunar`。
- 根 `package.json` 设 `packNpmManually: true` + `packNpmRelationList`（`./package.json` → `./miniprogram`）。
- 小程序用到的 npm 包须在**仓库根目录**安装，由开发者工具"构建 npm"打入 `miniprogram/`。
