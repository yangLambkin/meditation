# 06 - 部署与运维

> 逆向自 `cloudfunctions/*/config.json`、`scripts/runCleanup.js`、`scripts/README.md`、`uploadCloudFunction.sh`、`project.config.json`、`project.private.config.json`。

---

## 1. 云函数部署

### 1.1 通过微信开发者工具上传
对每个云函数目录右键 → **「上传并部署：云端安装依赖」**（即 `cloudfunctions/` 下每个子目录逐一上传）。

### 1.2 脚本模板
- `uploadCloudFunction.sh`：单行部署模板，仅调用 DevTools CLI 上传**指定函数**，**不是通用部署脚本**，需将脚本内函数名改为目标云函数后使用。

### 1.3 依赖说明
- 云函数运行时依赖 `wx-server-sdk` **按每个云函数各自安装**（各自 `package.json`）。
- 根目录 `node_modules/` 为空，不可直接在根目录跑云函数。

### 1.4 定时器（Timer Trigger）
- `cloudfunctions/meditationManager/config.json` 定义触发器：
  ```
  "triggers": [{ "name": "generateRankingSnapshot",
                 "type": "timer",
                 "config": "0 0 */6 * * * *" }]
  ```
  每 6 小时调用 `generateRankingSnapshot`（按 `daily` 等类型生成 `ranking_snapshots`）。

## 2. 数据库集合初始化

### 2.1 一次性建集合
- `cloudfunctions/autoCreateCollections/`：一次性引导函数，创建所有集合并写入**样例 schema / 样例数据**。
- ⚠️ **默认不在 `app.js` 中自动调用**（调用被注释）。集合缺失时须**手动触发**此云函数（上传后手动调用一次）。
- `create_collections_consistent.js` 与 `scripts/create_team_collections.js` 为 schema 参考/规范定义，**不自动执行**，仅作文档与对照。

## 3. 测试数据清理

### 3.1 前置条件
- 安装并登录**微信开发者工具**（CLI 可用 `cli cloud function invoke`）。
- 已上传 `cleanupTestData` 云函数。
- 在 `scripts/runCleanup.js` 的 `CONFIG.testPeriod` 调整安全清理的日期范围（默认 `2026-01-01 → 今天`）。

### 3.2 npm 脚本（`package.json`）
```bash
npm run cleanup:stats   # 仅展示各集合数据数量
npm run cleanup:safe    # 删除测试日期范围内的记录（默认 2026-01-01 → 今天）
npm run cleanup:full    # 删除全部记录（不可逆，需输入 "yes" 确认）
```
实现：上述脚本通过 DevTools `cli cloud function invoke` 调用 `cleanupTestData`（`scripts/runCleanup.js` 为 CLI 封装，`scripts/cleanupTestData.js` 为备选帮助脚本）。

### 3.3 清理模式
- `stats`：统计各集合记录数，不删数据。
- `safe`：按 `testPeriod` 日期范围删除（推荐日常使用）。
- `full`：清空所有记录，需二次确认。

## 4. npm 构建（小程序端）

- `project.private.config.json` 启用 `skylineRenderEnable`、`lazyCodeLoading`。
- `packNpmManually: true` + `packNpmRelationList` 指向 `./package.json` → `./miniprogram`：小程序依赖（`lunar` 等）须在**仓库根**安装，再用开发者工具「构建 npm」打包进 `miniprogram/`。

## 6. 运维注意事项

- `autoCreateCollections` 务必在**每个新环境**手动跑一次，否则集合缺失会导致运行时报错。
- 排行榜快照依赖定时器；若云函数未配置触发器，快照不会自动生成（实时榜不依赖快照，仍可用）。
- 镜像/占位：`file_index.json` 跟踪已上传背景图，`images/` 为本地静态图。
