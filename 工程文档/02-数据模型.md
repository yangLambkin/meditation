# 02 - 数据模型

> 逆向自 3 个 schema 定义文件：
> 1. `cloudfunctions/autoCreateCollections/index.js` —— 运行时**规范**集合定义（建集合 + 样例数据）
> 2. `create_collections_consistent.js` —— 按 API 字段镜像的**参考** schema
> 3. `scripts/create_team_collections.js` —— 团队 / 邀请领域**规范** schema（camelCase）
>
> 字段命名风格提醒：集合内混用 `camelCase`（`user_stats`、`meditation_records`）与 `snake_case`（`experience_records`、`user_mappings`、以及 `autoCreateCollections` 里的团队集合）。编辑时**沿用目标集合现有风格，不要统一**。

---

## 1. 集合总览

| 集合 | 职责 | 标注 |
| --- | --- | --- |
| `users` | 用户档案 | 实时 |
| `meditation_records` | 每次打卡一行 | 实时 |
| `experience_records` | 独立心得笔记 | 实时（自 2026 起与冥想记录解耦） |
| `user_stats` | 聚合统计 / 勋章 / 排行数据源 | 实时 |
| `rankings` | 日/月/总排行榜 | ⚠️ **遗留**：仍在写入，已不被读取 |
| `ranking_snapshots` | 定时生成的排行榜快照 | 实时（定时器每 6h） |
| `user_mappings` | `openid` ↔ `local_user_id` | 实时 |
| `teams` | 团队信息 | 实时 |
| `team_members` | 团队成员关系 | 实时 |
| `invites` | 邀请凭证 | 实时 |
| `invite_actions` | 邀请动作流水 | 实时 |
| `wisdom_quotes` | 每日智慧语 | 实时（`getRandomWisdom` 读取） |
| `images` | 已上传云存储图片目录 | 暂未启用写入路径（原 `recordUploadedImages` 已移除） |

---

## 2. 数据字典

### 2.1 `users`（用户档案）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `nickName` | string | 昵称 |
| `avatarUrl` | string | 头像 |
| `isCustomAvatar` | bool | 是否自定义头像 |
| `dataSource` | string | `'wechat'` \| `'custom'` |
| `migrationStatus` | string | 迁移状态 |
| `gender` | number | 性别 |
| `country` | string | 国家 |
| `province` | string | 省 |
| `city` | string | 市 |
| `createTime` | number | 创建时间 |
| `lastLoginTime` | number | 最近登录 |
| `loginCount` | number | 登录次数 |
| `profileComplete` | bool | 档案是否完整 |
| `originalInfo` | object | 原始信息（迁移保留） |

### 2.2 `meditation_records`（打卡记录）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `_openid` | string | 用户 openid |
| `date` | string | 日期 `YYYY-MM-DD` |
| `timestamp` | number | 打卡时刻（ms） |
| `duration` | number | 时长（分钟） |
| `rating` | number | 评分（⚠️ 类型不一致，见 07） |
| `experience` | **array** | 体验记录 id 数组（⚠️ `create_collections_consistent.js` 里为 string，运行时为数组） |
| `createdAt` | number | 创建时间 |
| `updatedAt` | number | 更新时间 |

### 2.3 `experience_records`（心得笔记，snake_case）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `_openid` | string | 用户 openid |
| `text` | string | 笔记内容 |
| `timestamp` | number | 创建时刻（ms） |
| `created_at` | number | 创建时间（snake） |
| `updated_at` | number | 更新时间（snake） |

> 自 2026 年起，`experience_records` 与 `meditation_records.experience` **解耦**，仅通过 id 数组关联，不再有外键式绑定。

### 2.4 `user_stats`（聚合统计，排行榜实时数据源）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `_openid` | string | openid |
| `totalDays` | number | 累计打卡天数 |
| `totalCount` | number | 累计打卡次数 |
| `totalDuration` | number | 累计时长（分钟） |
| `dailyTotalDuration` | number | **当日**总时长（排行榜依据，跨天重置） |
| `monthlyTotalDuration` | number | 当月累计时长（跨月累加重置） |
| `longestCheckInDays` | number | 最长连续打卡天数 |
| `currentStreak` | number | 当前连续天数 |
| `longestStreak` | number | 历史最长连续天数 |
| `lastCheckinDate` | string | 最近打卡日期 |
| `lastCheckinDuration` | number | 最近打卡时长 |
| `lastCheckin` | string | 最近打卡时间（字符串） |
| `monthlyStats` | object | `{ 'YYYY-MM': { days, count, totalDuration } }` |
| `badges` | object | 勋章解锁状态（存于此集合内） |
| `nickname` | string | 昵称缓存 |
| `createdAt` | number | 创建时间 |
| `updatedAt` | number | 更新时间 |

### 2.5 `rankings`（⚠️ 遗留）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `_openid` | string | openid |
| `type` | string | `daily` \| `monthly` \| `total` |
| `period` | string | 周期标识 |
| `duration` | number | 时长 |
| `count` | number | 次数 |
| `updatedAt` | number | 更新时间 |

> 每次打卡仍由 `updateRankings` 写入此集合，但 `getRankings` 已改为实时读 `user_stats`，**此集合不再被读取**。

### 2.6 `ranking_snapshots`（快照）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `type` | string | 榜单类型 |
| `period` | string | 周期 |
| `snapshotTime` | number | 快照时间 |
| `rankings` | array | `[{ openid, nickname, duration, rank }]` |
| `totalUsers` | number | 参与用户数 |

### 2.7 `user_mappings`（snake_case）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `_openid` | string | 真实 openid |
| `local_user_id` | string | 本地 ID（`local_...`） |
| `created_at` | number | 创建时间 |
| `updated_at` | number | 更新时间 |

### 2.8 `teams`（团队信息）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `teamId` | string | 团队 ID（运行时，camelCase） |
| `teamName` | string | 团队名 |
| `teamIcon` | string | 团队图标 |
| `createdBy` | string | 创建者 openid |
| `createdAt` | number | 创建时间 |
| `memberCount` | number | 成员数 |
| `updatedAt` | number | 更新时间 |

> ⚠️ `autoCreateCollections/index.js` 里团队集合用的是 `team_id` / `inviter_openid` 等 snake_case，与运行时 `teamManager` 的 camelCase（`teamId`/`inviterId`/`openid`/`joinedAt`）**不一致**，存在字段错配风险，见 `07`。

### 2.9 `team_members`（团队成员）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `teamId` | string | 团队 ID |
| `openid` | string | 成员 openid |
| `joinedAt` | number | 加入时间（camelCase；autoCreate 里为 `joined_at`） |
| `role` | string | 角色 |
| `nickname` | string | 昵称 |
| `avatarUrl` | string | 头像 |
| `isCreator` | bool | 是否创建者 |

### 2.10 `invites`（邀请凭证）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `inviteId` | string | 邀请 ID |
| `teamId` | string | 团队 ID |
| `teamName` | string | 团队名 |
| `inviterId` | string | 邀请人 openid（autoCreate 里为 `inviter_openid`） |
| `inviterName` | string | 邀请人昵称 |
| `expireAt` | number | 过期时间 |
| `createdAt` | number | 创建时间 |
| `status` | string | 状态 |

### 2.11 `invite_actions`（邀请动作流水）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `inviteId` | string | 邀请 ID |
| `openid` | string | 动作人 |
| `action` | string | 动作类型 |
| `timestamp` | number | 时间 |

### 2.12 `wisdom_quotes`（每日智慧语） & `images`（图片目录）
- `wisdom_quotes`：由 `getRandomWisdom` 随机读取一行（具体字段未在本仓库 schema 中定义，依赖云数据库已存在内容）。
- `images`：记录已上传云存储的图片集合；原写入云函数 `recordUploadedImages` 已移除，当前无写入路径。
