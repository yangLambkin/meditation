# 02 - 数据模型

本文保留微信云端记录与旧团队的数据字典，实际字段以云函数读写代码为准。`autoCreateCollections`、`create_collections_consistent.js`、`scripts/create_team_collections.js` 是初始化/参考定义，不能当作完整生产 schema 或升级脚本。

功课与新建团队存于 bijing-data，分别见 [功课记录](../docs/2026-10-31-practice-records.md) 与 [团队 OpenAPI](../docs/team-openapi.md)。同步、绑定和审批集合见对应功能部署说明。现有集合混用 camelCase 与 snake_case，修改时沿用实际字段，不批量更名。

---

## 1. 集合总览

| 集合 | 职责 | 标注 |
| --- | --- | --- |
| `users` | 用户档案 | 实时 |
| `meditation_records` | 每次打卡一行 | 实时 |
| `experience_records` | 独立心得笔记 | 实时（自 2026 起与冥想记录解耦） |
| `user_stats` | 聚合统计 / 勋章 / 排行数据源 | 实时 |
| `rankings` / `ranking_snapshots` | 旧排行榜与快照 | 遗留集合；当前不再写入或定时生成 |
| `user_mappings` | `openid` ↔ `local_user_id` | 实时 |
| `teams` | 团队信息 | 实时 |
| `team_members` | 团队成员关系 | 实时 |
| `invites` | 邀请凭证 | 实时 |
| `invite_actions` | 邀请动作流水 | 实时 |
| `wisdom_quotes` | 每日智慧语 | 按需读取（客户端每天缓存一条，北京时间 02:00 换日） |
| `images` | 已上传云存储图片目录 | 暂未启用写入路径（原 `recordUploadedImages` 已移除） |

## 2. 数据字典

### 2.1 `users`（用户档案）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `nickName` | string | 昵称 |
| `avatarUrl` | string | 头像 |
| `isCustomAvatar` | bool | 是否自定义头像 |
| `dataSource` | string | `'wechat'` \| `'custom'` |
| `migrationStatus` | string | 迁移状态 |
| `gender` | number | 性别 |
| `country` | string | 国家 |
| `province` | string | 省 |
| `city` | string | 市 |
| `createTime` | number | 创建时间 |
| `lastLoginTime` | number | 最近登录 |
| `loginCount` | number | 登录次数 |
| `profileComplete` | bool | 档案是否完整 |
| `originalInfo` | object | 原始信息（迁移保留） |

### 2.2 `meditation_records`（打卡记录）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `_openid` | string | 用户 openid |
| `date` | string | 静坐业务日期 `YYYY-MM-DD`，北京时间当天 02:00（含）至次日 02:00（不含）；手动补录保留所选日期 |
| `timestamp` | number / string | 打卡时刻；新记录使用毫秒值，读取兼容历史时间格式 |
| `duration` | number | 时长（1–1440 整数分钟） |
| `rating` | number | 历史评分兼容字段 |
| `experience` | array | 体验记录 id 数组；读取兼容历史字符串 |
| `localId` / `idempotencyKey` | string | 同次记录的稳定身份，重试复用 |
| `source` / `dateSource` | string | 计时或手动来源；手动记录保留所选业务日 |
| `createdAt` | number | 创建时间 |
| `updatedAt` | number | 更新时间 |

### 2.3 `experience_records`（心得笔记，snake_case）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `_openid` | string | 用户 openid |
| `text` | string | 笔记内容 |
| `timestamp` | number | 创建时刻（ms） |
| `created_at` | number | 创建时间（snake） |
| `updated_at` | number | 更新时间（snake） |

> 自 2026 年起，`experience_records` 与 `meditation_records.experience` **解耦**，仅通过 id 数组关联，不再有外键式绑定。

### 2.4 `user_stats`（聚合统计，排行榜实时数据源）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `_openid` | string | openid |
| `totalDays` | number | 累计打卡天数 |
| `totalCount` | number | 累计打卡次数 |
| `totalDuration` | number | 累计时长（分钟） |
| `dailyTotalDuration` | number | **当日**总时长（排行榜依据，跨天重置） |
| `monthlyTotalDuration` | number | 当月累计时长（跨月累加重置） |
| `longestCheckInDays` | number | 最长连续打卡天数 |
| `currentStreak` | number | 当前连续天数 |
| `longestStreak` | number | 历史最长连续天数 |
| `lastCheckinDate` | string | 最近打卡日期 |
| `lastCheckinDuration` | number | 最近打卡时长 |
| `lastCheckin` | string | 最近打卡时间（字符串） |
| `monthlyStats` | object | `{ 'YYYY-MM': { days, count, totalDuration } }` |
| `badges` | object | 勋章解锁状态（存于此集合内） |
| `nickname` | string | 昵称缓存 |
| `createdAt` | number | 创建时间 |
| `updatedAt` | number | 更新时间 |

### 2.7 `user_mappings`（snake_case）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `_openid` | string | 真实 openid |
| `local_user_id` | string | 本地 ID（`local_...`） |
| `created_at` | number | 创建时间 |

### 2.8 `teams`（团队信息）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `teamId` | string | 团队 ID（运行时，camelCase） |
| `teamName` | string | 团队名 |
| `teamIcon` | string | 团队图标 |
| `createdBy` | string | 创建者 openid |
| `createdAt` | number | 创建时间 |
| `memberCount` | number | 成员数 |
| `updatedAt` | number | 更新时间 |

> 此处仅描述旧微信团队。新建团队由 data OpenAPI 管理，不写入这些微信集合。

### 2.9 `team_members`（团队成员）
| 字段 | 类型 | 说明 |

| `nickname` | string | 昵称 |

### 2.11 `invite_actions`（邀请动作流水）
| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `inviteId` | string | 邀请 ID |
| `openid` | string | 动作人 |
| `action` | string | 动作类型 |
| `timestamp` | number | 时间 |

### 2.12 `wisdom_quotes`（每日智慧语） & `images`（图片目录）
- `wisdom_quotes`：由 `getRandomWisdom` 随机读取一行（具体字段未在本仓库 schema 中定义，依赖云数据库已存在内容）。
- 首页与分享卡片经 `utils/dailyWisdom.js` 共用当日金句，首次成功读取后缓存到本机；北京时间当天 02:00 至次日 02:00 使用同一句，页面持续显示时也会在分界点重新读取。不同设备独立抽取，清除本地缓存后会重新抽取；请求失败的默认句不缓存，重新打开页面可重试。
- `images`：记录已上传云存储的图片集合；原写入云函数 `recordUploadedImages` 已移除，当前无写入路径。

## 3. 同步与控制集合

- `meditation_locks` 保存事务版本、稳定身份及删除凭证；不是可以随意删除的缓存。
- 绑定、批次、失败与恢复进度集合及索引见 [批量同步](../docs/2026-09-23-admin-batch-sync.md) 和 [自动恢复](../docs/2026-10-10-auto-sync-recovery.md)。
- 反馈与补录的数据及权限见 [反馈](../docs/2026-09-29-feedback.md) 和 [补录](../docs/2026-10-05-backfill.md)。
- `rankings`、`ranking_snapshots` 和 `images` 的历史数据不在代码瘦身中删除；移除源码引用不等于授权清理数据库。
